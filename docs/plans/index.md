# 实施计划 (Implementation Plans) 索引

实施计划（Implementation Plan）用于将已达成共识的架构决策或 RFC 方案，拆解为可被开发人员和 Coding Agent 逐步执行的具体开发阶段、检查点与测试验证矩阵。

## 🚀 执行规范

1. **先计划后落地**：中大型任务必须编写 Implementation Plan 并与用户/团队确认后再动工；
2. **渐进式实施**：将任务划分为若干独立、可验证的阶段（Phases）；
3. **验证驱动**：每个阶段必须附带对应的单元测试或自动化回归验证。
